# last30days Skill 中文说明

## 1. Skill 的作用

last30days 是面向近期信息的调研技能。它会围绕一个人、公司、产品或主题，汇集 Reddit、Hacker News、GitHub、Polymarket 等来源的近 30 天信号，并整理成带来源的研究简报。

## 2. 使用场景

- 调研 AI、产品、行业或竞品的最新讨论。
- 会见客户、创始人或合作方前，快速了解近期动态。
- 追踪招聘信号、开源项目活跃度与用户反馈。
- 为内容选题、产品决策或投资研究补充近期证据。

## 3. 使用方法

安装后在 Codex 中直接说明调研对象和时间范围，例如：

```text
请用 last30days 调研过去 30 天 AI 编程 Agent 的重要变化，按热度和可信来源整理。

请调研某公司最近 30 天的产品发布、招聘信号和社区反馈，并附上来源链接。
```

第一次运行可按向导配置扩展数据源。建议先使用无需配置的 Reddit、HN、GitHub 等来源，再按需要接入其他平台。

## 4. 安装方法

```bash
npx skills add mvanhorn/last30days-skill@last30days -g
```

本机已安装到全局 Agent Skills 目录。重新开启 Codex 会话后使用。

## 5. 是否收费

- 技能本身免费，采用 MIT 开源许可。
- Reddit、Hacker News、GitHub 等基础来源可直接使用。
- X、YouTube、TikTok、Perplexity 或特定搜索服务可能要求自备 API Key、登录会话或模型额度，因此可能产生第三方费用。
- Codex 本身的订阅或模型用量不包含在技能中。
