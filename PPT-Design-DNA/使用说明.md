# PPT-Design-DNA 中文使用说明

## 1. Skill 的作用

PPT-Design-DNA 是一个以“Design DNA”为核心的演示文稿设计 Skill。它不会把内容直接塞进固定模板，而是先从参考图中提取版式、字体、配色、留白、图片节奏和视觉风险，形成一套可复用的设计规则，再据此生成整套 HTML 演示稿。

默认交付是便于视觉检查和迭代的 HTML deck；完成后可按需要导出 PDF 或 PPTX。它适合希望从品牌画册、杂志内页、秀场视觉、服装 Lookbook 中提炼设计语言，而不是只需要一份常规商业汇报的人。

## 2. 使用场景

### 时尚女装画册排版

这是最适合的使用场景之一。使用时应提供两类素材：

- **风格参考图**：品牌画册、杂志跨页、竞品 Lookbook、版式参考。它们只用于提取设计气质，默认不会直接放进画册。
- **内容图**：本季服装主图、细节图、面料图、模特图、搭配图、品牌 logo。这些图片会被纳入页面排版。

适合制作：

- 季度女装 Lookbook、订货会画册、系列发布册。
- 品牌型录、设计师作品集、主题胶囊系列提案。
- 将已有时尚杂志或品牌视觉转化为统一的页面设计系统。
- 同一品牌长期复用的画册风格 Profile。

也适合产品发布、作品集和创意策略类演示。它不适合只有大量表格、需要多人逐页在 PowerPoint 中微调，或完全没有图片素材却要求真实时尚画册效果的任务。

## 3. 使用方法

### 推荐工作流

1. 先提供 2 到 5 张风格参考图，以及全部需要展示的服装内容图。
2. 明确说明画册用途、受众、页数、尺寸、品牌名、系列主题、字体和色彩限制。
3. 先要求 Skill 提取 Design DNA，确认视觉方向后再生成整套画册。
4. 生成 HTML 初稿后，逐页检查图片裁切、文字可读性、留白、系列节奏和服装细节是否正确。
5. 确认无误后再导出 PDF；只有确实需要 PowerPoint 编辑时才要求导出 PPTX。

### 女装画册示例

```text
使用 PPT-Design-DNA 制作 16 页的 2026 春夏女装 Lookbook。

我会提供 3 张时尚品牌画册作为风格参考图，以及 28 张本季服装内容图。
先只提取 Design DNA，不要生成画册：重点分析网格、留白、字体层级、
图片裁切比例、跨页节奏和配色。

受众是买手和订货客户；风格要克制、现代、有高级感；
画面主角必须是服装，不要生成无关的模特或产品替代图。
确认 Design DNA 后，再生成 16 页横版 HTML 画册，并在最后导出 PDF。
```

### 复用品牌风格示例

```text
使用 PPT-Design-DNA，复用我保存的「品牌 2026 Lookbook」Design Profile。
本次为秋冬针织系列做 12 页画册；沿用网格、字体和留白，
但把主色从奶油白调整为冷灰与酒红。先给出页面结构和每页图片需求，
得到确认后再生成。
```

## 4. 安装方法

### 使用 Codex 安装器

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo dakjdakd/PPT-Design-DNA \
  --path . \
  --name PPT-Design-DNA
```

安装位置为：

```text
~/.codex/skills/PPT-Design-DNA/
```

安装完成后开启新的 Codex 对话，再说“使用 PPT-Design-DNA”或“根据参考图生成一套画册风格”即可调用。

## 5. 注意事项

- 参考图不是内容图。若希望某张服装图出现在画册中，必须明确把它作为内容图提供。
- 时尚画册的成败主要取决于服装图片质量、图片命名与分组、系列叙事和参考图质量；Skill 不能修复缺失或模糊的产品素材。
- 默认 HTML 输出通常比 PPTX 更利于保持复杂版式。若客户需要在 PowerPoint 中修改大量文字或图片，应在制作前明确提出，并预留人工验收时间。
- 不要混用过多不同品牌的参考图，否则会提取出相互冲突的视觉规则。建议同一套画册只选择 1 到 2 个主参考方向。
