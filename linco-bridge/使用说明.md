# Linco Bridge 中文说明

## 1. Skill 的作用

Linco Bridge 不是传统的提示词 Skill，而是一套本地连接器与桥接服务。它让运行在电脑上的 AI Agent CLI（包括 Codex、Claude Code、Hermes、OpenClaw）保持在本机执行，同时从 Web、H5、小程序、App、IM 或自定义客户端远程访问会话、流式输出、授权请求、附件和生成文件。

核心组件是 `linco-connect`：

- 在本机连接 Codex CLI 与 Linco 频道或自建频道。
- 将 Agent 的流式回答、工具调用、权限确认和长任务状态呈现在远端客户端。
- 支持官方 Linco App、官方演示平台，或自行部署参考平台并开发自定义前端。
- 保持 Agent 实际执行、会话与文件处理在个人电脑，不把 Agent CLI 迁移到云端。

## 2. 使用场景

- 用手机 App、H5 或小程序访问电脑上正在运行的 Codex 会话。
- 希望为本地 Agent 建立专用 Web、IM、企业内应用或客户界面。
- 本地测试 Agent 的远程会话、附件传递、权限确认与流式输出能力。
- 团队希望参考官方 NestJS + UniApp 示例，自托管一套 Agent 桥接平台。

不适合的场景：

- 只需要在 Codex 桌面应用内使用 Skill；此工具不会增强提示词能力。
- 需要无需配置即可把本地会话公开到互联网的方案；必须先授权、配置频道，并自行承担网络与安全设计。

## 3. 使用方法

### 快速连接官方 Linco App

1. 安装 Linco App（iOS TestFlight 或 Android APK）。
2. 在 App 的 **Bridge** 页面选择导入 Agent，并选择 Codex。
3. App 会生成专属的连接命令；复制到运行 Codex CLI 的电脑终端执行。
4. 确认连接器在线后，在 App 内向该 Codex 会话发送测试消息。

命令通常类似以下形式，其中令牌必须使用平台为你生成的真实值：

```bash
linco-connect init --token "<app-id>:<app-secret>" --agent codex
linco-connect start --daemon
```

### 使用官方演示站或微信小程序

1. 打开 [Linco Bridge Hosted Demo](https://bridge-demo.lincotalk.com) 或微信小程序“agent桥接器”。
2. 在 Bridge 中选择导入 Codex。
3. 运行页面生成的 `setupCommands`。
4. 返回页面刷新连接状态，再选择项目或会话测试。

该演示环境使用匿名访客会话，不适合传输生产数据、敏感文件或长期保存的数据。

### 自托管参考平台

仓库提供 NestJS 后端和 UniApp Web 参考实现：

```bash
git clone https://github.com/lincotalk/linco-bridge.git
cd linco-bridge/linco-bridge-platform/server
npm install
npm run start:dev
```

另开一个终端启动 Web 前端：

```bash
cd linco-bridge/linco-bridge-platform/web
npm install
npm run dev:h5
```

打开命令输出的 H5 地址，在 Bridge 中导入 Codex，并执行平台生成的连接器初始化命令。自托管环境应配置 HTTPS/WSS、认证、数据保留和审计策略。

### 常用连接器命令

```bash
# 查看本机环境、配置与 Agent 兼容性
linco-connect doctor

# 查看连接器状态
linco-connect status

# 以前台方式启动
linco-connect start

# 以后台守护进程启动
linco-connect start --daemon

# 停止连接器
linco-connect stop
```

## 4. 安装方法

Linco Bridge 的本机连接器需要 Node.js 20 或 22 至 26；官方推荐 Node.js 22 LTS。安装命令为：

```bash
npm install -g linco-connect
```

安装后验证：

```bash
linco-connect --version
linco-connect doctor
```

本机已安装 `linco-connect 1.2.43`，并已确认：Node.js、Codex CLI 与网络检查通过。当前没有配置你的平台 IM Token，因此不会自动连接或启动后台服务；应从 Linco App、演示站或自托管平台取得令牌后再执行 `init`。

## 安全注意

- 不要把 `appSecret`、token、私钥、认证 URL 或用户数据提交到 GitHub、聊天记录或日志中。
- 公网部署应使用 HTTPS/WSS；`ws://` 仅用于可信的本地调试。
- TLS/WSS 本身不等同于端到端加密，仍需要设计认证、权限、数据存储和审计。
- 注意限制隐藏路径和敏感文件的传递范围。
