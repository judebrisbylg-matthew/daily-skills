# Generative-Media-Skills 中文说明

## 1. Skill 的作用

Generative-Media-Skills 是一组通过 MuAPI 生成和编辑图像、视频、音频的多媒体工作流。它不是单一 skill，而是一套由 `muapi-cli` 驱动的创作能力：agent 根据任务选择合适的生成模型、组织结构化提示词、提交生成请求并处理结果。

本次实际安装了 13 个可用工作流：

- `muapi-ad-creative`：多尺寸广告创意与文案变体。
- `muapi-ai-clipping`：长视频自动识别并剪辑为短视频片段。
- `muapi-cinema-director`：电影级镜头语言与视频生成指导。
- `muapi-instagram-post`：品牌化 Instagram 图文内容。
- `muapi-logo-creator`：简洁的 logo 创意与品牌标识。
- `muapi-nano-banana`：结构化推理式图像生成。
- `muapi-product-video-ad-maker`：由产品图生成短视频广告。
- `muapi-seedance-2`：文生视频、图生视频和视频延展。
- `muapi-social-media-video`：面向社媒平台的视频内容。
- `muapi-ugc-video-factory`：人物图、产品图和脚本组合的 UGC 广告。
- `muapi-ui-design`：高保真网页或移动端 UI 视觉设计。
- `muapi-youtube-shorts`：YouTube Shorts 选题、剪辑和发布向内容。
- `muapi-youtube-thumbnail`：YouTube 缩略图创意与生成。

底层服务通过 MuAPI 提供图片、视频、音频、抠图、放大、换脸、口型同步等能力。它支持异步任务：先提交请求并获得 `request_id`，再查询或等待结果。

## 2. 使用场景

适合用于：

- 产品广告图、社媒配图、缩略图和品牌视觉素材。
- 商品图转 5 到 10 秒短视频广告。
- UGC 风格种草视频、口播素材和竖屏短视频。
- 视频自动剪辑、长视频提炼和 Shorts/Reels/TikTok 分发素材。
- 视频分镜、镜头描述、图生视频和视频延展。
- logo、UI 概念稿、海报和品牌设计探索。

它特别适合“从创意简报到可用媒体资产”的工作流；对于简单的单张图生成，也可以直接使用 Codex 自带的 imagegen，避免额外 API 费用和配置。

## 3. 使用方法

在新的 Codex 对话中，直接描述目标媒体、使用平台、尺寸、已有素材和希望的风格。带有产品图、人物图或品牌素材时，说明哪些内容必须保留。

示例：

```text
使用 muapi-product-video-ad-maker，把这张香水产品图做成 8 秒竖屏广告。
画面要有微距玻璃反光、缓慢推镜和高级感；用于小红书；不要出现新的品牌文字。
```

```text
使用 muapi-nano-banana 为我的咖啡品牌生成一张横版主视觉。
主体是手冲咖啡与玻璃器具；光线是清晨窗边侧光；
画面比例 16:9；保留留白用于后期放标题。
```

```text
使用 muapi-ai-clipping 从这段访谈视频中找出 3 个适合短视频传播的高信息密度片段，
输出竖屏裁切和每条的标题建议。
```

### 使用前配置

skill 文件安装完成后，还需要配置个人的 MuAPI API Key，才能调用付费生成服务：

```bash
muapi auth configure
```

按终端提示输入 API Key 即可。请不要把 API Key 写入 GitHub、提示词、截图或项目源码。完成配置后可先查看可用模型：

```bash
muapi models list
```

生成视频等耗时任务时，建议用异步方式提交并保存返回的 `request_id`，然后查询完成状态并下载成品。

## 4. 安装方法

### 方式一：官方一键安装整包

```bash
npx skills add SamurAIGPT/Generative-Media-Skills --all
```

这会安装仓库中被 skills 工具识别的全部工作流。当前版本识别并安装 13 个 skills。

### 方式二：只安装某一个 skill

```bash
npx skills add SamurAIGPT/Generative-Media-Skills --skill muapi-media-generation
```

### 安装运行依赖

核心媒体调用依赖 `muapi-cli`：

```bash
npm install -g muapi-cli
muapi auth configure
```

安装后可用下面的命令确认 CLI 已可启动：

```bash
muapi --version
```

## 注意事项

- 安装 skill 不等于已开通生成服务。实际生成会消耗 MuAPI 账户额度，并需要你自己的 API Key。
- 图像、视频、音频和剪辑结果应在发布前人工检查，尤其是品牌名称、人物相貌、字幕、音乐授权和平台合规性。
- 涉及人物照片、客户素材或内部视频时，先确认是否允许上传到第三方 API。
- 请谨慎使用换脸、口型同步和名人相关的生成能力，遵守肖像权、版权和平台规则。
- 不要把 API Key 提交到 GitHub；优先使用 `muapi auth configure` 或本机环境变量配置。
