# Taste Skill 中文说明

## 1. Skill 的作用

Taste Skill 是前端视觉质量增强技能，重点改善页面布局、留白、字体层级、颜色、动效和组件细节，减少 AI 生成页面常见的模板化与千篇一律问题。

本次安装的是核心模块 `design-taste-frontend`。

## 2. 使用场景

- 用 Codex 新建网页、后台、落地页或移动端界面。
- 希望重做已有页面的视觉层级和设计风格。
- 将截图、品牌参考或设计方向转成可实现的前端界面。
- 需要在简约、工业、品牌化等不同视觉方向间选择。

## 3. 使用方法

直接提供产品目标、受众、页面类型和品牌约束，例如：

```text
用 Taste Skill 设计一个基金投资仪表盘，要求信息密度高、克制、便于扫描，避免营销页风格。

请重做当前页面的布局和排版，保留功能，重点解决层级混乱和卡片过多的问题。
```

如需图片参考板、品牌套件或图生代码，可再按需要安装该仓库的其他模块。

## 4. 安装方法

```bash
npx skills add leonxlnx/taste-skill@design-taste-frontend -g
```

本机已安装到全局 Agent Skills 目录。重新开启 Codex 会话后使用。

## 5. 是否收费

- 核心技能免费，采用 MIT 开源许可。
- 本次安装的前端设计模块不要求额外 API。
- 使用仓库中的图片生成相关模块时，所选图片模型或 API 可能收费。
- Codex 的订阅或模型用量另计。
