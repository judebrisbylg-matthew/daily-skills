# Superpowers Skill 中文说明

## 1. Skill 的作用

Superpowers 是一套面向软件开发任务的工程化工作流插件。它把复杂开发工作拆成可执行的步骤，并引导 Codex 在合适的时机进行需求澄清、方案设计、测试驱动开发、代码审查和交付验证。

它不替代 Codex 的编程能力，而是为开发过程补上稳定的“做事方法”：先理解问题，再规划；先写能暴露问题的测试，再实现；完成后再复核代码和验证行为。

核心能力包括：

- 需求澄清与方案分解：把模糊想法转为明确的实现步骤。
- 测试驱动开发（TDD）：先定义预期行为，再实现代码。
- 调试工作流：系统地缩小问题范围、定位原因并验证修复。
- 代码审查：检查逻辑错误、边界条件、可维护性和测试缺口。
- 任务收尾：在交付前做验证，避免“看起来完成但实际不可用”。

## 2. 使用场景

Superpowers 特别适合以下工作：

- 新功能开发：需求包含多个步骤、多个文件或需要评估取舍时。
- 修复线上或难复现的缺陷：需要有条理地定位根因，而不是反复试改。
- 重构既有代码：需要控制改动范围，并验证行为没有退化。
- 接手陌生项目：先建立对项目结构、约束与风险点的理解。
- 准备提交或合并代码：希望在提交前补一轮工程质量检查。
- 协作开发：把执行过程、决策和验证依据沉淀得更清晰。

对于一次性的小修改，例如改一行文案或调整一个配置值，直接说明目标通常更快，不必刻意启动完整流程。

## 3. 使用方法

安装并重启 Codex 后，直接用自然语言描述开发任务即可。Superpowers 会在适合的时机启用相应工作流。

推荐的提问方式：

```text
为这个需求先梳理实现方案和风险点，确认后再修改代码。

这个测试失败了，请按系统化调试流程定位根因并修复，最后运行相关测试。

请为这个新接口采用测试驱动开发：先补测试，再实现，再做代码审查。

提交前对本次改动做一次严格代码审查，重点检查边界条件、错误处理和测试遗漏。
```

使用建议：

1. 面对复杂任务，先让它输出方案与关键假设，确认方向再进入修改。
2. 涉及业务规则时，提供可验证的示例输入、预期输出和异常情况。
3. 修复问题时，附上报错信息、复现步骤和相关文件路径。
4. 在任务结束时明确要求运行测试或执行验收步骤。

## 4. 安装方法

### 方式一：Codex 插件目录安装（推荐）

1. 在 Codex 中打开 Plugins（插件）目录。
2. 搜索 `Superpowers`。
3. 选择官方提供的 **Superpowers** 插件并点击安装。
4. 重启 Codex，确保新增的工作流被加载。

### 方式二：Codex CLI 安装

如果使用 Codex CLI，可在交互界面执行：

```text
/plugins
```

然后搜索 `Superpowers`，选择安装即可。安装后重新启动当前 Codex 会话。

## 注意事项

- Superpowers 会让复杂开发任务更规范，但通常会增加少量规划、测试和审查时间；它适合质量要求较高的代码工作。
- 它是流程增强工具，不会自动理解未提供的业务背景。需求越具体，结果越可靠。
- 安装第三方插件时，应优先选择官方插件目录中的版本，并在涉及生产环境、密钥或外部发布操作时保留人工确认。
