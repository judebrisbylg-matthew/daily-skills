# Humanizer-zh Skill 中文说明

## 1. Skill 的作用

Humanizer-zh 用于识别并减弱中文文本中的 AI 写作痕迹，让表达更自然、具体，读起来更像经过真人编辑的内容。

它重点处理以下常见问题：

- 夸大意义、宣传式和空泛的表达。
- "此外"、"至关重要"、"不断演变的格局"等高频 AI 词汇。
- 模糊归因，例如"专家认为"、"行业报告显示"却不提供具体来源。
- 公式化的三段式列举、"不仅……而且……"、过多破折号和连接词。
- 句式过于整齐、节奏单一、结尾空泛的文本。
- 过度客套、聊天记录残留和知识截止日期免责声明。

它会在不改变核心含义的前提下，删除填充词，改用清楚的事实、具体细节和更自然的句子节奏。必要时还会给出 50 分制的质量评分，评估直接性、节奏、信任度、真实性和精炼度。

## 2. 使用场景

适合用于：

- 优化小红书、公众号、博客、产品介绍和社媒文案。
- 编辑 AI 初稿，使其更接近个人的表达风格。
- 审阅 README、提案、汇报材料和邮件，删除空话与模板化表达。
- 将冗长、泛泛的说明压缩为更具体、易读的文字。
- 在发布内容前进行一轮“AI 味”检查。

不适合用它替代事实核验、法律审核或专业内容校对。它优化的是写作风格；日期、数据、引用和业务结论仍应由作者确认。

## 3. 使用方法

安装并重启 Codex 后，直接贴出待修改文本，并说明使用场景、目标读者和希望保留的语气即可。

示例：

```text
请用 Humanizer-zh 改写下面这段小红书文案。
保留轻松、第一人称的语气；删掉空泛宣传，不要编造数据；输出改写后的文案和 3 条关键改动说明。

[在这里粘贴原文]
```

也可以提出更具体的要求：

```text
审阅这篇公众号文章，找出 AI 写作痕迹。保留专业语气和所有已给出的事实，
把模糊归因标出来，不确定的信息不要替我补充。
```

该 skill 的标准处理流程是：

1. 扫描 AI 写作模式。
2. 改写有问题的片段，同时保留原意和既有事实。
3. 调整句子长短与语气，使行文不再公式化。
4. 输出改写后的文本，并按需要简要说明改动与质量评分。

## 4. 安装方法

### 方式一：使用 skills 命令

```bash
npx skills add https://github.com/op7418/Humanizer-zh.git
```

### 方式二：使用 Codex 内置安装器

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo op7418/Humanizer-zh \
  --path . \
  --name humanizer-zh
```

安装完成后重启 Codex 或开启一个新的对话，确保技能被加载。

## 注意事项

- 先说明目标平台和语气。例如：小红书、公众号、技术文档、品牌公告或朋友间聊天，改写效果会更稳定。
- 要求“保留所有数字、专有名词、引用和结论”，可以降低改写时意外改变事实的风险。
- 不要为了“更像真人”而无中生有地添加个人经历、数据或观点。
- 对需要正式、克制表达的公文或合规材料，应避免注入过多第一人称和情绪化表达。
