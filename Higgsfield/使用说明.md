# Higgsfield 中文使用说明

## 1. Skill 的作用

Higgsfield 是官方提供的一组 AI 视觉生产 Skill，通过 Higgsfield CLI 调用图片、视频和品牌视觉生成能力。它不是单一功能，而是一套可组合的视觉制作工具。

当前安装的 8 个 Skill：

| Skill | 作用 |
| --- | --- |
| `higgsfield-generate` | 生成图片、视频、3D 或音频；也可用于品牌广告和视频传播效果评分。 |
| `higgsfield-product-photoshoot` | 制作棚拍、生活方式图、Pinterest 图、横幅、广告素材、虚拟试穿和产品重风格化图片。 |
| `higgsfield-soul-id` | 训练可复用的人物身份，获得用于后续生成的一致性 `reference_id`。 |
| `higgsfield-brandkit` | 建立或延展品牌视觉体系，包括色彩、logo、字体、包装、社媒图和品牌手册。 |
| `higgsfield-marketplace-cards` | 生成电商主图、详情页辅助图和 A+ 风格模块。 |
| `higgsfield-video-explainer` | 制作旁白型非真人讲解视频。 |
| `higgsfield-youtube-thumbnail` | 制作 YouTube 缩略图与竖版视频封面。 |
| `higgsfield-websites` | 创建、编辑和部署网站；需要额外的 Git、Bun 与 Cloudflare 环境。 |

## 2. 使用场景

### 时尚女装与画册制作

最值得优先使用的是：

- `higgsfield-product-photoshoot`：服装棚拍、模特上身、生活方式图、Pinterest 情绪图、广告素材与虚拟试穿。
- `higgsfield-generate`：服装系列视频、UGC 试穿、产品展示、社媒短视频和画册所需的辅助视觉。
- `higgsfield-soul-id`：需要同一个虚拟模特在多张图、多支视频中保持面部一致时使用。
- `higgsfield-brandkit`：需要把 Lookbook、社媒、包装和宣传物统一成品牌系统时使用。

电商详情页优先使用 `higgsfield-marketplace-cards`；讲解视频和封面分别使用 `higgsfield-video-explainer`、`higgsfield-youtube-thumbnail`。

## 3. 使用方法

安装和登录完成后，在 Codex 中直接说明目标、素材、输出比例和限制条件。Skill 会根据任务匹配对应流程。

### 女装产品图示例

```text
使用 higgsfield-product-photoshoot。

基于我提供的女装产品图，制作 4 张 2:3 的秋冬针织系列视觉：
1 张白底电商主图、1 张高级感棚拍、1 张城市生活方式图、1 张 Pinterest 情绪图。
保持服装版型、颜色、纹理和配饰准确；先给出每张图的构图与提示词，再生成。
```

### 一致虚拟模特示例

```text
先使用 higgsfield-soul-id 为我提供的人物照片建立 Soul ID。
完成后，使用同一 Soul ID 生成 6 张女装 Lookbook 模特图，要求脸部一致、服装按我提供的产品图准确呈现、每张构图不同。
```

### 视频示例

```text
使用 higgsfield-generate，为这套女装系列做一条 9:16、8 秒的短视频。
主体是模特自然行走和展示服装面料细节；不要改变产品颜色、版型和图案。
先说明将使用的模型、镜头节奏和预计积分消耗，再执行生成。
```

生成结果必须人工检查服装细节、手部、面部一致性、文字准确性和产品真实性。AI 生成图不应替代真实商品图的最终核对。

## 4. 安装与登录方法

### 安装 Skill 到 Codex

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo higgsfield-ai/skills \
  --path higgsfield-generate higgsfield-soul-id higgsfield-product-photoshoot \
    higgsfield-brandkit higgsfield-marketplace-cards higgsfield-websites \
    higgsfield-video-explainer higgsfield-youtube-thumbnail
```

### 安装 CLI 并登录

```bash
curl -fsSL https://raw.githubusercontent.com/higgsfield-ai/cli/main/install.sh | sh -s -- --prefix="$HOME/.local" --no-hf
higgsfield auth login
```

第二条命令会打开官方浏览器登录页。完成授权后，才可以真正提交生成任务。

安装位置：

```text
~/.codex/skills/higgsfield-*/
~/.local/bin/higgsfield
```

## 5. 费用与注意事项

- Skill 与 CLI 的安装免费。
- 生成图片、视频、重试和放大通常消耗 Higgsfield Credits。Higgsfield 提供有限免费层，但通过 CLI 或 Skill 生成仍按积分计费。
- 使用前先在 Higgsfield 账户确认当前套餐、可用模型和积分余额；不同模型、清晰度与视频时长的消耗不同。
- `higgsfield-websites` 的部署流程会创建和推送网站代码，应仅在明确需要建站时使用。
- 官方文档列出 9 个 Skill，但当前官方仓库仅提供上述 8 个 `SKILL.md` 目录；未发现 `higgsfield-game-generation` 的可安装源码，因此本次未安装它。
