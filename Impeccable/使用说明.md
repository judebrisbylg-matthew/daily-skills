# Impeccable Skill 中文说明

## 1. Skill 的作用

Impeccable 是网页与产品界面的设计工作流技能。它提供设计规划、UX 评审、可访问性检查、排版、布局、动效、响应式适配、性能优化和最终打磨等命令，用于让已有界面从“能用”提升到更完整、一致和可交付的状态。

## 2. 使用场景

- 新功能上线前进行设计和技术质量检查。
- 对现有网页做 UX、排版、响应式和可访问性审查。
- 修复移动端适配、文本溢出、空状态和错误状态。
- 需要将页面纳入统一设计系统，或做最终视觉打磨。

## 3. 使用方法

可用自然语言描述需要打磨的范围，也可使用其命令式工作流，例如：

```text
用 Impeccable 审查当前仪表盘的 UX、层级、移动端适配和可访问性，并实施必要的修复。

请对结账页面做最终 polish，检查错误状态、文字溢出、键盘操作和性能。
```

典型命令包括 `critique`（设计评审）、`audit`（技术质量检查）、`polish`（最终打磨）、`adapt`（多设备适配）和 `animate`（有目的的动效）。

## 4. 安装方法

```bash
npx skills add pbakaus/impeccable@impeccable -g
```

本机已安装到全局 Agent Skills 目录。项目如需启用 Impeccable 的 Codex hook，可另执行官方安装器，并在 Codex 的 `/hooks` 页面审核和批准 hook。

## 5. 是否收费

- 技能免费，采用 Apache-2.0 开源许可。
- 使用基本设计审查和工作流不要求额外服务费用。
- 若启用图片生成或其他外部能力，相关模型/API 可能收费。
- Codex 的订阅或模型用量另计。
