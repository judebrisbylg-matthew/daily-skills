# Caveman Skill 中文说明

## 1. Skill 的作用

Caveman 让编程 Agent 用非常精简的方式表达结论，并可配合压缩机制减少上下文输入与输出的 token。它保留问题结论和操作建议，主动省略客套、重复解释和长篇叙述。

## 2. 使用场景

- 高频编程、调试和代码审查，想降低 token 消耗。
- 需要快速阅读结论、命令和待办，而不需要教学式解释。
- 长对话、长日志或多轮任务中希望减少上下文压力。

## 3. 使用方法

安装后可明确要求使用简洁模式，例如：

```text
用 Caveman 风格分析这个报错：只给根因、修改位置和验证命令。

接下来所有进度更新保持 Caveman 风格，简短列出完成项、阻塞项和下一步。
```

它适合熟悉技术背景的工作。若需要向非技术人员解释，或需要完整方案与取舍说明，应明确要求正常详细回答。

## 4. 安装方法

```bash
npx skills add JuliusBrussee/caveman@caveman -g
```

本机已安装到全局 Agent Skills 目录。重新开启 Codex 会话后使用。
