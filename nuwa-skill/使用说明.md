# nuwa-skill 中文说明

## 1. Skill 的作用

`nuwa-skill`（女娲造人）用于把一个人物、主题，或一个尚不明确的需求，沉淀成可供 AI 调用的独立 Skill。

它的目标不是模仿某个人的语气，更不是伪造其观点，而是提炼可复用的：

- 思维模型：此人或主题用于理解问题的核心框架。
- 决策启发式：在不确定条件下的判断原则与取舍方式。
- 表达 DNA：常用概念、论证节奏、语言偏好和风格特征。
- 价值观、反模式和张力：其明确反对什么、观点中有哪些条件或矛盾。
- 诚实边界：适用范围、证据不足处和不能替代的专业判断。

对于明确的人物或主题，它会走“直接构建”流程；对于“我想要一个帮我做决策的顾问”这类模糊需求，它会先诊断需求，再推荐 2 至 3 个合适的人物或主题方向。

最终会生成一个可运行的 `SKILL.md`，并可选保留调研资料、来源和测试记录，方便后续更新与审查。

## 2. 使用场景

- 想以某位公开人物的思维框架分析问题，例如商业、投资、产品或创作决策。
- 想把一个领域方法论沉淀为主题 Skill，例如价值投资、产品克制、叙事设计或谈判。
- 已有自己的文章、访谈、会议纪要、决策备忘录等材料，想提炼为个人思维顾问。
- 需求还不清晰，希望先获得“应找什么类型顾问”的候选建议。
- 现有 Skill 需要补充新的公开资料、修正模型或扩大覆盖主题。

不适合的情况：

- 冒充真人、生成“此人一定会说”的虚构原话。
- 用少量二手材料强行给人物下结论。
- 将私密资料、未经授权的素材或敏感个人信息写入可分享的 Skill。

## 3. 使用方法

### 直接构建人物或主题 Skill

在对话中给出对象、聚焦方向和用途。例如：

```text
用 nuwa-skill 为我构建一个“芒格式投资决策”Skill。
聚焦长期主义、机会成本和风险控制，用于分析我的投资备选方案。
使用标准档调研，并在关键阶段先让我确认。
```

也可以构建主题 Skill：

```text
用 nuwa-skill 创建“产品克制”主题 Skill，
用于评审新功能是否真正解决用户问题，避免无效堆功能。
```

### 从模糊需求开始

```text
我需要一个能帮我在复杂商业决策中看清取舍的思维顾问。
请先诊断我的需求，并给出 2 至 3 个适合构建成 Skill 的候选方向。
```

它会先问 1 至 2 个关键问题，再说明候选对象的适配度、限制和预期调研成本。

### 使用本地材料蒸馏自己或团队的方法

```text
用 nuwa-skill 蒸馏我的产品决策方法。
素材在 /path/to/materials，包含文章、访谈转录和决策备忘录；
优先使用这些材料，不足时再补充公开资料。
```

可提供 PDF、文章、访谈逐字稿、字幕文件、博客、会议纪要和决策备忘录等。高质量的一手材料越多，结果越可信。

### 选择调研档位

- 快速档：覆盖约 3 个研究维度，适合先做可用原型。
- 标准档：默认选项，系统研究写作、对话、表达方式、外部评价、关键决策和时间线。
- 深度档：尽量覆盖完整一手资料，适合长期使用的重要人物或主题，但耗时和 token 成本更高。

典型流程是：确认对象、用途与档位 -> 多源调研 -> 展示调研摘要供确认 -> 提炼框架 -> 展示 Skill 设计供确认 -> 生成、测试并打磨 Skill。它会区分事实与推导，并在证据不足时保留限制说明。

## 4. 安装方法

在终端执行：

```bash
npx skills add https://github.com/alchaincyf/nuwa-skill.git
```

安装完成后，重新打开或新建一个 Codex 对话，使新 Skill 被加载。

本机已通过 Git 稀疏检出安装到：

```text
~/.codex/skills/nuwa-skill
```

如需为 Codex 明确指定仓库根目录，也可使用内置安装脚本：

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo alchaincyf/nuwa-skill \
  --path . \
  --name nuwa-skill \
  --method git
```

## 使用注意

- 这是一个高投入调研流程。人物越复杂、档位越深，所需时间和 token 越多。
- 优先采用原始著作、演讲、访谈和可靠的一手资料；不要把低质量转载当作事实依据。
- 不应复制长篇原文、伪造引语或把推断写成事实。
- 对仍在世且非公众人物，应先确认授权和素材使用范围。
- 生成后的 Skill 仍需要由使用者审核，尤其是涉及投资、法律、医疗等高风险决策时。
