# teach 中文使用说明

## 1. Skill 的作用

`teach` 是一个面向长期学习的 Skill。它会把一个独立文件夹作为学习空间，围绕你明确的学习目标，持续产出带来源引用的短课程、练习、复习资料和学习记录。

它的重点不是一次解释完一个问题，而是让后续课程能根据已经学过的内容继续推进。学习资料通常包括：

- `MISSION.md`：学习目标和真实使用目的。
- `RESOURCES.md`：课程依据的高可信来源。
- `lessons/`：分阶段的 HTML 课程。
- `reference/`：便于反复查看的速查表、术语表或方法卡。
- `learning-records/`：已掌握内容和下一步学习依据。

## 2. 使用场景

适合：

- 系统学习时尚画册排版、品牌视觉、PPT 设计方法或 AI 生图工作流。
- 学习英语、某个软件、代码框架或专业认证知识。
- 需要连续数周学习，并希望每次课程能承接上一次进度的主题。

不适合：

- 只想临时弄懂一个概念。此时直接向 Codex 提问更快。
- 希望它自动记住所有项目工作。跨对话项目上下文不属于 `teach` 的职责。

## 3. 使用方法

`teach` 不会自动触发，需要主动说明要开启学习项目。建议为每个主题建立一个单独文件夹或 Git 仓库，避免与实际工作项目混在一起。

### 示例：学习时尚女装画册排版

```text
使用 teach，为我创建一个「时尚女装画册排版」学习项目。

目标是在 6 周内能独立完成 16 页女装 Lookbook 的版式规划。
我希望重点学习：图片叙事、网格、字体层级、留白、跨页节奏与 PDF 输出检查。
请先确认学习目标和课程大纲，再开始第一节课；每节课都要给出处和一个可执行练习。
```

### 持续学习

后续打开同一个学习文件夹后，可以这样继续：

```text
使用 teach，继续「时尚女装画册排版」的下一节课。
先回顾我上一节练习中的薄弱点，再安排一个难度适中的新练习。
```

学习内容由模型整理，涉及精确流程、技术参数或专业规范时，仍应查看课程引用的原始资料并自行验证。

## 4. 安装方法

### 推荐：安装到 Codex

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo mattpocock/skills \
  --path skills/productivity/teach \
  --name teach
```

安装位置：

```text
~/.codex/skills/teach/
```

安装后，请开启新的 Codex 对话，再明确说“使用 teach”并说明学习主题。

## 5. 费用与注意事项

- Skill 源码免费。
- 是否消耗模型额度或检索额度，取决于你使用的 Codex 模型与可用工具。
- 一次只维护一个清晰的学习主题；主题跨度太大时，应拆分为多个学习空间。
