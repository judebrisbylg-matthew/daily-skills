# Camofox Browser 中文使用说明

## 1. Skill 的作用

`camofox-browser` 是一个本地浏览器自动化 Skill。它通过 Camofox Browser Server 驱动基于 Camoufox 的 Firefox 浏览器，为 Codex 提供页面打开、点击、输入、滚动、截图、无障碍快照、结构化提取和下载等能力。

它不是普通搜索工具，也不是 Lovart 的自动化插件。安装后会在本机启动一个浏览器服务，默认只监听本机地址 `127.0.0.1:9377`。

## 2. 使用场景

适合在拥有授权的前提下使用：

- 自己的网站或公司内部系统的页面回归测试、表单流程检查和 UI QA。
- 从公开网页中提取允许收集的文本、链接、图片或结构化信息。
- 需要用浏览器完成重复的内部运营操作，且目标平台明确允许自动化。
- 通过无障碍快照让 Codex 更稳定地识别网页元素并进行测试。

不适合：

- 绕过登录、验证码、访问控制、付费墙、反爬机制或平台风控。
- 对 Lovart 进行批量高频生成、自动化提交、规避检测或规避账号限制。
- 未经网站或平台许可采集数据、操作账号或批量下载内容。

Lovart 的服务条款禁止使用机器人、爬虫或其他自动化技术访问服务；脚本化或非人类高频行为可能触发账号审核或临时停用。因此，Lovart 工作流应保留人工登录、提交生成和结果验收环节。

## 3. 使用方法

### 启动与检查服务

```bash
camofox server start --background
camofox server status
```

服务默认地址：

```text
http://127.0.0.1:9377
```

### 基础命令

```bash
# 打开页面
camofox open https://example.com

# 获取页面无障碍快照和元素编号
camofox snapshot

# 点击编号为 e5 的元素
camofox click e5

# 向编号为 e3 的输入框填写内容
camofox type e3 "hello world"

# 截图
camofox screenshot --output page.png

# 查看当前标签页
camofox get-tabs

# 停止服务
camofox server stop
```

在 Codex 中也可以明确说明任务，例如：

```text
使用 camofox-browser 检查我自己的测试站点注册流程。
只读取页面和填写测试账号，不要提交最终注册；输出每一步的页面元素、错误提示和截图。
```

使用时必须明确目标网站、授权范围、是否允许提交表单或下载文件。登录、付款、发布内容、删除数据和上传敏感素材等操作，应由用户人工确认或完成。

## 4. 安装方法

### 安装本地 CLI 服务

```bash
npm install -g camofox-browser
```

如果首次安装的自动下载步骤未完成，可先稳定安装包，再手动下载浏览器引擎：

```bash
npm install -g camofox-browser --ignore-scripts
node ~/.local/node-v22.23.1/lib/node_modules/camofox-browser/node_modules/camoufox-js/dist/__main__.js fetch
```

不同 Node.js 安装路径可能不同。若 `~/.local/node-v22.23.1` 不存在，应根据 `npm root -g` 返回的位置替换路径。

### 安装 Codex Skill

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo redf0x1/camofox-browser \
  --path skills/camofox-browser \
  --name camofox-browser
```

安装位置：

```text
~/.codex/skills/camofox-browser/
```

完成后开启新的 Codex 对话，即可在合规的浏览器测试或公开资料采集任务中调用。

## 5. 费用与注意事项

- Skill 和本地服务均为开源软件，采用 MIT 许可证，安装免费。
- 代理、云服务器、目标网站会员或第三方数据服务可能另行收费。
- Camofox 会在 `~/.camofox/profiles/` 保存浏览器会话资料；其中可能包括 Cookie 和本地存储。不要共享该目录，也不要在不可信环境中复制其中的文件。
- 服务应保持仅本机监听。不要把 `9377` 端口暴露到公网；若确实需要局域网或远程调用，必须设置访问密钥并进行网络隔离。
- 浏览器自动化并不保证不会被网站识别，也不能作为规避平台规则的手段。
