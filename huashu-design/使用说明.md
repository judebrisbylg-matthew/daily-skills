# huashu-design Skill 中文说明

## 1. Skill 的作用

huashu-design（花叔 Design）是一个面向视觉产出的设计工作流 skill。它用 HTML、CSS 和必要的前端组件制作高保真原型、演示幻灯片、动画、信息图和可视化，而不是用于开发带后端的生产级 Web 应用。

它强调“设计从内容和真实资产中长出来”，而不是套用通用模板。主要能力包括：

- 制作可点击的产品原型与网页视觉稿。
- 制作 1920×1080 的 HTML 幻灯片，并支持导出 PDF 或可编辑 PPTX。
- 制作动效 Demo、产品 UI 演示和可导出的 MP4/GIF。
- 制作信息图、数据可视化和单页设计物料。
- 对已有设计按视觉层级、细节、功能性等维度进行专家评审。

它内置反“AI 设计套路”规则，避免无关的渐变、装饰性图标、编造的数据和廉价 SVG 插画；涉及真实品牌或产品时，要求先核实事实并优先使用官方 logo、产品图和 UI 截图。

## 2. 使用场景

适合用于：

- 产品功能原型、活动页、信息面板和交互演示。
- 路演 PPT、培训课件、方案汇报和视觉化文档。
- 产品发布动画、概念短片、UI 功能演示。
- 小红书图文卡、活动海报、信息图和视觉内容草稿。
- 需要比较多个视觉方向的品牌或产品设计任务。
- 对现有设计做结构化评审和改进建议。

不适合用于：

- 需要账号、数据库、支付、服务端接口等完整功能的生产级 Web App。
- 以 SEO、长期内容运营或后端业务逻辑为核心的网站开发。
- 只需修改一段纯文字、导出文件或修复小错误的机械任务。

## 3. 使用方法

安装并重启 Codex 后，直接描述要设计的内容、受众、输出形式和已有素材。涉及具体产品或品牌时，提供 logo、产品图、截图、品牌色或参考链接，效果会明显更好。

示例：

```text
用 huashu-design 为我的 AI 记账产品做一个 iOS 高保真原型。
目标用户是年轻上班族；展示首页、账单详情和预算提醒；
品牌色是深绿和米白；输出可点击的 HTML 原型。
```

```text
用 huashu-design 做一份 8 页的产品路演 PPT，主题是智能健身镜。
已有 logo 和三张产品照片。先给我 3 个真实视觉方向供选择，
我选定后再完成整套幻灯片并导出 PDF。
```

### 关键工作流

1. 明确目标、受众、核心信息和输出尺寸；同时提供或索取品牌资产与参考。
2. 对任何新视觉设计，先给出 3 套可见的真实方向稿，而不是只用文字列风格选项。
3. 用户从方向稿中选择或组合方案后，再深化为完整原型、幻灯片或动画。
4. 涉及具体品牌、产品或版本信息时，先联网核实事实，并使用真实的 logo、产品图或 UI 截图。
5. 交付前用浏览器或 Playwright 截图检查版式、交互和控制台错误。

当你明确说“直接做一版，不用出三版”时，skill 可以跳过三方向流程；否则它会先停在方向选择处等待确认。这是为了避免在错误方向上投入完整制作时间。

## 4. 安装方法

### 方式一：使用 skills 命令

```bash
npx skills add https://github.com/alchaincyf/huashu-design.git
```

### 方式二：使用 Codex 内置安装器

该仓库默认分支为 `master`，根目录就是 skill：

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo alchaincyf/huashu-design \
  --ref master \
  --path . \
  --name huashu-design
```

安装完成后重启 Codex 或开启一个新的对话，确保 skill 被加载。

## 注意事项

- 它的核心产出是视觉设计和原型，不应把它当作通用前端开发器。
- 没有真实图片、品牌资产或数据时，优先使用明确标注的占位内容，不要编造看似真实的素材。
- 动画、PPT 和多屏原型通常需要更长的制作与验证时间；先确认方向可以显著减少返工。
- 包含外部品牌、产品或最新技术信息时，先核实产品状态、规格和官方素材，避免把过时或错误事实做进设计。
