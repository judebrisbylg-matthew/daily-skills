# Agency Agents 视觉与设计角色中文说明

## 1. 这是什么

Agency Agents 是一组可安装到 Codex 的专业角色 Agent。每个角色由一份提示词、工作流程和交付标准组成；安装后，Codex 可以在处理对应任务时采用该角色的专业视角。

本目录记录已安装的 10 个视觉、设计和体验相关角色。它们不是独立的软件或在线服务，不会自动登录第三方平台、生成图片或替代人工审批；实际产出仍取决于你提供的任务背景、素材和可用工具。

## 2. 已安装角色与使用场景

| 角色 | 主要作用 | 适合场景 |
| --- | --- | --- |
| `ui-designer` | 设计界面、组件、设计系统、视觉层级与页面布局。 | 网站、App、后台、活动页、组件规范。 |
| `ux-researcher` | 从用户需求、行为和痛点出发进行调研与可用性分析。 | 新功能立项、用户访谈提纲、可用性问题诊断。 |
| `ux-architect` | 规划信息架构、任务路径、交互规则及设计实现规范。 | 复杂产品流程、导航重构、设计系统落地。 |
| `brand-guardian` | 维护品牌定位、语气、视觉一致性和规范。 | 品牌升级、多个页面统一、内容与视觉审校。 |
| `visual-storyteller` | 将产品卖点或复杂信息组织成清晰的视觉叙事。 | 品牌介绍页、发布页、方案汇报、内容专题。 |
| `whimsy-injector` | 增加恰当的趣味细节、微交互和辨识度，降低模板感。 | 产品体验打磨、营销页、空状态、动效建议。 |
| `inclusive-visuals-specialist` | 审核图片、人物和视频表达的真实性、包容性及文化适配性。 | 全球化产品、品牌视觉、AI 生成图片审核。 |
| `persona-walkthrough-specialist` | 代入不同用户角色走查页面，定位理解和操作摩擦。 | 上线前体验验收、转化路径检查、无障碍与新手流程检查。 |
| `ui-finish-gate-reviewer` | 在交付前审查界面的完成度、品牌辨识度和细节质量。 | 网页或 App 上线前的视觉 QA、设计评审。 |
| `data-visualization-engineer` | 选择合适图表并设计可读、准确、可访问的数据表达。 | 数据看板、经营报告、趋势分析、交互图表。 |

## 3. 使用方法

在 Codex 中直接描述任务即可。为了让角色被准确选用，建议在请求中写出角色名，并说明目标用户、业务目标、已有素材和最终交付物。

### 示例

```text
请以 ui-designer 和 ux-architect 的视角，重做这个投资看板首页。
目标用户是每天查看市场和基金表现的个人投资者；保留现有数据字段；
先给出信息架构和桌面端页面结构，再实现页面。
```

```text
请以 persona-walkthrough-specialist 的视角，分别代入新用户、老用户和视力较弱用户，
走查这个注册流程，列出每一步的理解障碍、操作风险和修复优先级。
```

```text
请以 data-visualization-engineer 的视角，评审这份月度经营数据。
说明每个指标应使用什么图表、哪些图可能造成误读，并给出可执行的改版方案。
```

```text
请以 ui-finish-gate-reviewer 和 brand-guardian 的视角，审查当前页面截图。
只列出会影响上线质量的问题，按严重程度排序，并给出具体修改建议。
```

### 推荐组合

- 做产品原型：`ux-architect` + `ui-designer`。
- 做上线前检查：`persona-walkthrough-specialist` + `ui-finish-gate-reviewer`。
- 做品牌或营销页：`brand-guardian` + `visual-storyteller` + `whimsy-injector`。
- 做图表或数据看板：`data-visualization-engineer` + `ui-designer`。
- 审核生成图片或跨文化视觉内容：`inclusive-visuals-specialist` + `brand-guardian`。

## 4. 安装方法

### 安装指定角色到 Codex

```bash
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents
./scripts/convert.sh --tool codex
./scripts/install.sh --tool codex --agent ui-designer,ux-researcher,ux-architect,brand-guardian,visual-storyteller,whimsy-injector,inclusive-visuals-specialist,persona-walkthrough-specialist,ui-finish-gate-reviewer,data-visualization-engineer
```

安装文件会写入：

```text
~/.codex/agents/
```

安装完成后，开启新的 Codex 对话即可使用。不要一次安装全部角色；优先安装与你的实际工作有关的少量角色，避免角色过多导致选择和维护成本上升。

## 5. 注意事项

- 这些角色提供的是专业视角和流程，不等于事实保证。涉及品牌、产品规格、市场数据或用户研究结论时，应先核实资料。
- 用户研究、包容性和品牌审查只能给出基于现有材料的判断；不能替代真实用户测试、法律审核或品牌负责人审批。
- 视觉设计任务中，提供真实 logo、产品截图、品牌规范和参考页面，通常比只给一句风格描述更有效。
- 角色可以组合使用，但单个任务建议先确定一个主角色，避免多个角色输出互相矛盾。
