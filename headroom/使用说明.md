# headroom Skill 中文说明

## 1. Skill 的作用

headroom 用于压缩 Agent 的上下文：例如 JSON 输出、构建日志、搜索结果、源代码和历史对话。目标是在保留关键信息的前提下，减少 token 占用并缩短响应。

## 2. 使用场景

- 测试、构建或爬虫产生大量日志。
- 需要阅读很长的 JSON、搜索结果或代码文件。
- 对话接近上下文长度上限。
- 希望 Agent 输出更简短、减少重复说明。

## 3. 使用方法

安装成功后可直接说：

```text
请用 headroom 压缩这段构建日志，只保留错误、根因和下一步。

上下文快满了，请把目前的任务状态压缩成可继续执行的要点。
```

## 4. 安装方法

计划使用的官方技能市场命令为：

```bash
npx skills add roman-ryzenadvanced/headroom-skill@headroom -g
```

## 5. 是否收费

- 技能市场页面标示为 0 美元。
- 它是上下文压缩指令，不需要独立 API；Codex 的正常订阅或模型用量仍适用。
