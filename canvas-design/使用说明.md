# canvas-design Skill 中文说明

## 1. Skill 的作用

canvas-design 是用于生成静态视觉作品的技能。它先建立设计哲学和视觉方向，再输出以图形、空间、颜色和排版为主的 PNG 或 PDF 成品。它不是 Canva 软件，也不用于常规网页组件开发。

## 2. 使用场景

- 制作海报、封面、活动主视觉和艺术化信息图。
- 需要单页静态视觉稿或可下载 PDF。
- 希望用统一的视觉哲学产出系列图像或多页视觉作品。

## 3. 使用方法

直接说明主题、规格和视觉意图，例如：

```text
用 canvas-design 为 AI 投资趋势报告制作一张 16:9 封面，输出 PNG，视觉克制、科技感强、文字极少。

请生成一张 A4 PDF 活动海报，主题为产品设计分享会，重点通过图形和空间表达信息。
```

该技能会优先追求视觉表达。若任务重点是可交互网页、表单或后台系统，应使用前端设计类技能。

## 4. 安装方法

```bash
npx skills add anthropics/skills@canvas-design -g
```

本机已安装到全局 Agent Skills 目录。重新开启 Codex 会话后使用。

## 5. 是否收费

- 技能免费，采用 Apache-2.0 许可。
- 不包含图像模型或文件生成服务的费用。
- 执行任务时消耗的 Codex 模型额度，仍按你的账户方案计算。
